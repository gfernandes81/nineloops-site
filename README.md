# Nine Loops site

The public pages of the game Nine Loops, served by GitHub Pages:

| Page | Portuguese (pt-BR) | English |
| --- | --- | --- |
| Home | `index.html` | `index-en.html` |
| Privacy policy | `privacidade.html` | `privacy.html` |
| Support | `suporte.html` | `support.html` |

The app links to the privacy policy from its settings. The store listings use the privacy
policy and the support page. When the game changes how it uses data, update both policy pages
and their date before the release.
